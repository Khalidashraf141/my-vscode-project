🔍 C++ Stream Statements

Error Identification & Best Practices Guide

(a)
cout << (void*) amount;
⚠️ CONDITIONALLY VALID
✓
Valid only if 'amount' is a pointer
The (void*) cast forces printing the memory address
✗
If amount is not a pointer → logic issue
(b)
cout << put("john");
❌ ERROR
✗
put() accepts only a single char
✓
Correct:
cout.put('J') or cout << "john"
(c)
cout << width();
❌ ERROR
✗
width() is not a free function
✓
Correct: cout.width()
(d)
int p = cout.width(10);
❌ ERROR
✗
width() returns streamsize, not int
✓
Correct:
std::streamsize p = cout.width(10);
(e)
cout.width(10).precision(3);
❌ ERROR
✗
width() returns a number, cannot chain methods
✓
Correct:
cout.width(10); cout.precision(3);
(f)
cout.setf(ios::scintific, ios::left);
❌ MULTIPLE ERRORS
✗
Typo: 'scintific' should be 'scientific'
✗
Flag mismatch: scientific (floatfield) cannot pair with left (adjustfield)
(g)
ch = cin.get();
✅ VALID
✓
cin.get() returns int; char assignment allowed
(h)
cin.get().get();
❌ ERROR
✗
cin.get() returns int, cannot call .get() on int
(i)
cin.get(c).get();
✅ VALID
✓
cin.get(c) returns cin, so chaining is allowed
(j)
cout << setw(5) << setprecision(2);
⚠️ VALID BUT INCOMPLETE
⚠
Valid syntax but prints nothing
✓
Requires #include <iomanip>
(k)
cout << resetiosflags(ios::left | ios::showpos);
✅ VALID
✓
Valid with #include <iomanip>
Removes specified flags
