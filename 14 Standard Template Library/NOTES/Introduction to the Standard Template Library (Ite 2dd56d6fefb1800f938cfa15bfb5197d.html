Introduction to the Standard Template Library (Iterators)

Iterators

Definition

Iterators behave like pointers and are used to access elements of a container. They are commonly used to traverse from one element to another, a process known as iterating through the container

Why Iterators are Important

  • Provide a uniform way to access different containers
  • Work with STL algorithms

Iterators are not actual pointers, behave like them

Traverse means:

To visit each element of a container or data structure one by one, usually in a systematic order.

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
		vector<int> v = {10, 20, 30};
		
		for(vector<int>::iterator it = v.begin(); it != v.end(); ++it){
				cout << *it << " ";
		}
}

Output

10 20 30

    • queue → only front() and back()
  • No begin() or end() functions

Applications of Container Classes

In C++, container classes (part of the Standard Template Library — STL) are used to store, manage, and manipulate collections of data efficiently. Each container is designed for specific real-world needs.

1. Dynamic Data Storage

Problem: Size of data is no known at compile time

Solution: Containers automatically resize

Used Containers:

  • vector
  • deque
  • list

vector<int> marks = {85, 90, 78};
marks.push_back(92); // dynamic growth

2. Fast Searching & Lookup

Problem: Need quick search by key

Solution: Associative containers

Used Containers

  • map
  • unordered_map
  • set

map<int, string> student;
student[101] = "Ali";

3. Maintaining Unique Data

Problem: Duplicate data not allowed

Solution: set and unordered_set

set<int> ids = {1,2,2,3}; // duplicates removed

4. Stack-Based Operations (LIFO)

Problem: Last In, First Out behavior

Solution: stack

stack<int> s;
s.push(10);
s.pop();

5. Queue-Based Operations (FIFO)

Problem: First In, First Out behavior

Solution: queue

queue<string> q;
q.push("Task1");
q.pop();

6. Priority-Based Processing

Problem: Highest priority task first

Solution: priority_queue

priority_queue<int> pq;
pq.push(30);
pq.push(10);
cout << pq.top(); //30

7. Efficient Insert/Delete Operations

Problem: Frequent insertions & deletions in middle

Solution: list

list<int> l = {1, 2, 3};
l.push_front(0);

Vectors

  • Vector is the most widely used container in the C++ Standard Template Library (STL).
  • It stores elements in contiguous memory locations, similar to an array.
  • Because of contiguous storage, it allows direct access to elements using the subscript operation ([ ]).
  • A vector can grow or shrink dynamically during program execution.
  • Memory is allocated and deallocated automatically at run time required.
  • Vectors provide fast access to elements due to their array-like structure.
  • The vector container supports random access iterators
  • It allows a wide range of iterator operations, making it compatible with most STL algorithms.
  • Vectors are commonly used when frequent access and dynamic resizing are required.

  1. at()
    • The at() member function of the vector class returns a reference to the element at the specified position
    • Because it returns a reference, the element can be both read and modified.
    • Unlike operation[], at() performs bounds checking
    • If the index is out of range, it throws an out_of_range exception.

Syntax

v.at(index);

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    // Reading element using at()
    cout << "Element at index 1: " << v.at(1) << endl;

    // Modifying element using at() (reference behavior)
    v.at(1) = 50;

    cout << "After modification:" << endl;
    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

Element at index 1: 20
After modification:
10 50 30

  1. back()
    • The back() member function of the vector class returns a reference to the last element in the vector
    • Since it returns a reference, the last element can be accessed and modified directly.
    • The vector must not be empty when calling back()

Synatx

v.back();

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    // Accessing last element
    cout << "Last element: " << v.back() << endl;

    // Modifying last element using back()
    v.back() = 100;

    cout << "After modification:" << endl;
    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

Last element: 30
After modification:
10 20 100

  1. begin()
    • The begin() member function returns an iterator pointing to the first element of the vector
    • By dereferencing this iterator (*begin()), we get a reference to the first element.
    • Since it is a reference, the first element can read and modified.
    • If the vector is empty, begin() equals end()

Syntax

v.begin(); // iterator to first element
*v.begin(); // reference to first element

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    // Accessing first element
    cout << "First element: " << *v.begin() << endl;

    // Modifying first element using begin()
    *v.begin() = 100;

    cout << "After modification:" << endl;
    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

First element: 10
After modification:
100 20 30

  1. capacity()
    • The capacity() member function of the vector class returns the current capacity of the vector
    • Capacity means the total number of elements that the vector can store without reallocating memory.
    • The capacity is greater than or equal to the size of the vector
    • Capacity changes automatically when more memory is required

Syntax

v.capacity();

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v;

    cout << "Initial capacity: " << v.capacity() << endl;

    v.push_back(10);
    v.push_back(20);
    v.push_back(30);

    cout << "Size: " << v.size() << endl;
    cout << "Capacity: " << v.capacity() << endl;

    return 0;
}
Initial capacity: 0
Size: 3
Capacity: 4

size() → number of elements currently stored

capacity() → memory allocated for future growth

  1. clear()
    • The clear() member function removes all elements from the vector
    • After calling clear() the size of the vector becomes 0
    • The capacity usually remains unchanged (memory is not released)
    • The vector object itself is still valid and can be resued

Syntax

c.clear();

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30, 40};

    cout << "Before clear:" << endl;
    cout << "Size: " << v.size() << endl;
    cout << "Capacity: " << v.capacity() << endl;

    v.clear();

    cout << "\nAfter clear:" << endl;
    cout << "Size: " << v.size() << endl;
    cout << "Capacity: " << v.capacity() << endl;

    return 0;
}

Output

Before clear:
Size: 4
Capacity: 4

After clear:
Size: 0
Capacity: 4
  • clear() removes all elements
  • Vector becomes empty
  • Capacity is not reduced
  • Use shrink_to_fit() if you want to release memory

  1. empty()
    • it returns a Boolean value (bool).
    • It checks whether the vector is empty or not.
bool empty() const;
  • Returns true → if vector has no elements
  • Returns false → if vector has at least one element

Example

vector<int> v;
if(v.empty())
    cout << "Vector is empty";

  1. end()
    • end() returns an iterator pointing just past the last element
    • It is not a reference to an element
    • Used mainly in loops and algorithms.
v.end(); // iterator, not element

  1. erase()
    • The erase() member function removes one element or a range of elements from a vector
    • It reduces the size of the vector.
    • Elements after the erased position are shifted left.
    • It returns in iterator pointing to the element that follows the last removed element

Syntax

v.erase(position); // erase single element
v.eraase(start_iterator, end_iterator); // erase range

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30, 40};

    v.erase(v.begin() + 1); // removes 20

    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

10 30 40

Important

  • erase() works with iterators, not indexes
  • Time complexity: O(n) (due to shifting)
  • Does not change capacity

Why do we use remove() with erase()

Because erase() alone cannot remove elements by value and remove() alone does not actually delete elements.

so we combine both → this is called the erase-remove idiom

What remove() actually does

remove(v.begin(), v.end(), 20);
  • it does NOT delete element
  • It shifts all elements =! 20 to the front
  • It returns an iterator to the new logical end

Example:

vector<int> v = {10, 20, 30, 20, 40};
remove(v.begin(), v.end(), 20);

Vector becomes (logically):

10 30 40 ? ?
  • Size is still the same
  • Extra value are unspecified
  • 20 is not erased from memory

What erase() does

v.erase(newEnd, v.end());
  • It actually deletes elements
  • Reduces vector size
  • Cleans up the extra elements at the end

Why Both need Together

v.erase(remove(v.begin(), v.end(), 20), v.end());
  1. remove() rearranges elements and returns new end
  1. erase() deletes unwanted tail elements

  1. insert()
    • The insert() member function inserts one or more elements into a vector
    • Insertion happens at a specified position
    • Elements after the insertion point are shifted right.
    • The size of the vector increases

Syntax

v.insert(position, value);                 // single element
v.insert(position, count, value);          // multiple same elements
v.insert(position, first, last);           // range insertion

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    v.insert(v.begin() + 1, 15); // insert 15 at index 1

    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

10 15 20 30

Example 2:

vector<int> v = {1, 2, 5};
v.insert(v.begin() + 2, 3, 9); //insert 3 copies of 9

Result:

1 2 9 9 9 5

  1. pop_back()
    • The pop_back() member function removes (deletes) the last element from the vector
    • It reduces the size of the vector by one
    • It does not return the deleted value.
    • The vector must not be empty before calling pop_back()

Syntax

v.pop_back();

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    v.pop_back();   // removes 30

    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

10 20

Important Points

  • Deletes only the last element
  • Size decreases, capacity unchanged
  • Time complexity: O(1)
  • Does not free memory

  1. push_back()
    • The push_back() member function adds (inserts) an element at the end of the vector.
    • The size of the vector increase by one.
    • Memory is allocated automatically if the current capacity is full.
    • Average time complexity is O(1) (amortized).

    Syntax

    v.push_back(value);

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20};

    v.push_back(30);   // adds element at the end

    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

10 20 30
  • May cause reallocation if capacity is full
  • Faster than insert() in the middle

  1. resize()
    • The resize() member function changes the size of the vector
    • It can increase or decrease the number of elements
    • If the size is increased, new elements are value-initialized (or filled with a given value).
    • If the size is decreased, extra elements are removed from the end.

    Syntax

    v.resize(new_size);
v.resize(new_size, value);

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v = {10, 20, 30};

    v.resize(5);   // increases size

    for(int x : v)
        cout << x << " ";

    return 0;
}

Output

10 20 30 0 0

Example 2:

vector<int> v = {1, 2, 3};
v.resize(6, 9);

Result:

1 2 3 9 9 9
  • resize() changes size, not capacity
  • Removing elements is O(1) form the end

  1. size()
    • The size() member function returns the current number of elements in the vector
    • It reflects how many elements are actually stored, not the allocated memory.
    • Time complexity: O(1)

Syntax

v.size();

  1. swap()
    • The swap() member function exchanges the contents of two vectors.
    • No element-by-element copying is done
    • Time complexity: O(1) very fast
    • Sizes and capacities of both vectors are swapped.

Syntax

v1.swap(v2);

Example Code

#include <iostream>
#include <vector>
using namespace std;

int main()
{
    vector<int> v1 = {1, 2, 3};
    vector<int> v2 = {10, 20};

    v1.swap(v2);

    cout << "v1: ";
    for(int x : v1) cout << x << " ";

    cout << "\nv2: ";
    for(int x : v2) cout << x << " ";

    return 0;
}

Output

v1: 10 20
v2: 1 2 3

lists - STL Container

What is lists?

  • list is s sequence container in the C++ STL
  • It stores elements in non-contiguous memory locations
  • Implemented internally as a doubly linked list.

Key Characteristics

  • Supports fast insertion and deletion at any position
  • No direct/random access (no [ ] operator)
  • Elements are accessed only using iterators.
  • Size can grow or shrink dynamically
  • Extra memory is used to store links (pointers).

Syntax

#include <list>
list<int> l;

Example Code

#include <iostream>
#include <list>
using namespace std;

int main()
{
    list<int> l = {10, 20, 30};

    l.push_front(5);
    l.push_back(40);

    for(int x : l)
        cout << x << " ";

    return 0;
}

Output

5 10 20 30 40

When to Use list

  • Frequent insertions/deletions in the middle
  • No need for random access
  • Managing sequence like:
    • Music playlists
    • Browser history
    • Undo/redo operations

What does Bidirectional mean in list?

In C++ STL, list provides bidirectional iterators.

This means:

  • You can move the iterator forward
  • You can move the iterator backward
  • But you cannot jump directly to any position (no random access)

Allowed Operations

For a list iterator it:

it++; // move to next element
it--; // move to previous element

No Allowed

it + 2;     // ❌ error
it - 1;     // ❌ error
l[3];       // ❌ no subscript operator

Why is it called Bidirectional?

Because internally, list is doubly linked list:

NULL ← [10] ⇄ [20] ⇄ [30] → NULL

Each node stores:

  • Data
  • Pointer to next node
  • Pointer to previous node

So traversal is possible in both directions

unique() — Removes Consecutive Duplicate Elements

  • unique() removes consecutive duplicate elements from a list
  • It compares neighboring elements only.
  • The list should be sorted first if you want to remove all duplicates
  • Works only with list and forward_list (no with vector directly).

Syntax

l.unique();

Example Code

#include <iostream>
#include <list>
using namespace std;

int main()
{
    list<int> l = {10, 10, 20, 30, 30, 20};

    l.unique();

    for(int x : l)
        cout << x << " ";

    return 0;
}

Output

10 20 30 20

Important Point

  • unique() removes only adjacent duplicates
  • To remove all duplicates:

l.sort();
l.unique();

splice()

  • splice() moves elements from one list to another
  • No copying is done — only pointers are adjusted
  • Very fast operation (O(1))
  • Source list loses the moved element

Syntax

l1.splice(pos,l2); // move all elements
l1.splice(pos, l2, it); // move one element
l1.splice(pos, l2, first, last); // move range

Example Code

#include <iostream>
#include <list>
using namespace std;

int main()
{
    list<int> l1 = {1, 2, 3};
    list<int> l2 = {10, 20};

    l1.splice(l1.end(), l2);

    cout << "l1: ";
    for(int x : l1) cout << x << " ";

    cout << "\nl2 size: " << l2.size();

    return 0;
}

Output

l1: 1 2 3 10 20
l2 size: 0

Why splice()

  • No element copying
  • No memory allocation
    • Nodes of list2 are detached
    • Their prev and next pointers are rewired
    • Nodes are attached into list1

No new memory is requested from heap

splice() does not allocate memory because it transfers existing nodes between lists by pointer manipulating in a doubly linked list, without creating or copying elements.

Maps

  • std::map is an associative container
  • Stores elements as (key, value) pairs
  • Keys are unique
  • Elements are automatically sorted by key
map<int, string> m;

Internal Working

  • Implemented using a Red-Black Tree (self-balancing BST)
  • Elements are NOT stored contiguously
  • Each element is stored in a separate node

Memory Allocation in map

  • Memory is allocated for each node individually
  • Allocation happens when:
    • insert()
    • operator[]
  • No reallocation like vector

map always allocates memory when inserting new elements

Insertion Methods

  1. insert()
map<int, int> m;
m.insert({1, 100})
  • Inserts only if key does not exist

  1. operator[]
m[2] = 200;
  • if key does not exist → creates a new node
  • Default-initializes value first

Accessing Elements

cout <<m[1];
cout <<m.at(1); // throws exception if key not found

Example Code

#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int,string> m;

    m[3] = "Three";
    m[1] = "One";
    m[2] = "Two";

    for(auto &p : m)
        cout << p.first << " -> " << p.second << endl;
}

Output(Sorted by key)

1 -> One
2 -> Two
3 -> Three

Why map::operator[] is considered dangerous

operator[] dangerous because accessing a non-existing key automatically inserts a new element with a default value, causing unintended memory allocation and logical bugs.

Example:

map<int, int> m;
int x = m[10];

Hidden behavior

  • key 10 does not exist
  • map creates a new node
  • Value is default-initialized → 0
  • Memory is allocated
  • Tree is rebalanced

You only wanted to read, but you modified the map

Use fin() (Best for checking)

auto it = m.find(key);
if(it != m.end())
		cout << it->second;

Use at() 

cout << m.at(key); // throws exception if missing

LIMITATIONS

  1. Use of standard template library should be avoided for real-time applications due to internal memory allocation.
  1. Use of standard library helps the programmer by adding precompiled headers but maximizes the compile time.
Deterministic means: The behavior of a system is completely predictable and repeatable

If you run the same operation under the same conditions, you always get the same result in the same amount time.

FUNCTION OBJECTS

Definition

A function object is a function that is wrapped inside a class, so that it behaves like an object.

  • The class overloads the function call operator ()
  • This allows the object to be called like a normal function

Hence, a function object looks like an object but behaves like a function.

Characteristics of Function Objects

  • Implemented as a Class
  • The class contains:
    • Only one member function
    • The overloaded operator()
  • Usually does not contain data members
  • The class is templatized
    • So it can work with different data types
  • Defined in the <functional> header file

Function Objects in STL Algorithms

STL provides predefined function objects that can be passed to algorithms.

Example Code Sorting in Descending Order

#include <algorithm>
#include <functional>
#include <iostream>
using namespace std;

int main() {
    int arr[] = {4, 2, 9, 1};
    sort(arr, arr + 4, greater<int>());

    for(int i = 0; i < 4; i++)
        cout << arr[i] << " ";
}

Output:

9 4 2 1
  • greater<int> is a function object
  • It is used to sort elements in descending order
