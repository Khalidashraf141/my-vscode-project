This diagram focuses only on files and streams

Input Stream
    - Reads data from disk file → into program
    - Class used: ifstream

Output Stream
    - Writes data from program → into disk file
    - Class used: ofstream

What the diagram teaches
    - Streams act like conveyors
    - Program does not interact with files directly — only through streams.
