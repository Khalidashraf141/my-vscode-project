15 Manipulating Strings

INTRODUCTION

What is a String in C++

A string is a sequence of characters.

Old way (C-strings)

char name[20] = "Khalid";

Problems:

  • Fixed size
  • Manual memory handling
  • No direct comparison, concatenation, etc.

Modern way (C++ string class)

#include <string>
string name = "Khalid";
  • Dynamic size
  • Safe
  • Powerful build-in functions
  • Easy to use

That’s why ANSI C++ introduced string class

Why string is NOT STL but behaves like one

Although string is not officially part of STL, it:

  • Works like a container
  • Supports iterators
  • Works with STL algorithms

So practically, we treat it like an STL container.

  1. string(const string &str)

    string s1 = "C++";
string s2(s1); // s2 = "C++"

    Creates a copy of another string object

append()

Adds one string to another

string a = "Hello";
string b = " World";
a.append(b);
cout << a;

Output

Hello World

Same as + but safer and faster.

assign()

Assigns new value (replaces old one)

string s;
s.assign("Balagurusamy");
cout << s;

Useful when reusing string variables.

at()

Access character at given index (safe)

string s = "CPLUS";
cout << s.at(2);

Output

L

Bounds-checked —> safer than []

begin()

Returns iterator to first character

string s = "ABC";
cout << *s.begin();

Output

A

Used with STL algorithms

capacity()

Total allocated storage capacity

string s = "Hello";
cout << s.capacity();

Capacity ≥ size

`compare()

Compares two strings lexicographically

string a = "Apple";
string b = "Banana";
cout << a.compare(b);

empty()

Checks if string is empty

string s;
if(s.empty())
		cout << "Empty string";

Very important before accessing characters.

end()

Returns iterator after last character

string s = "ABC";
auto it = s.end();
it--;
cout << *it;

Output

C

erase()

Removes characters

string s = "HelloWorld";
s.erase(5,5);
cout << s;

Output

Hello

(start, length)

find()

Finds substring position

string s = "Programming";
cout << s.find("gram");

Output

3

Returns string::npos if not found

insert()

Inserts characters

string s = "Hello";
s.insert(5, " World");
cout << s;

Output

Hello World

length() / size()

Returns number of characters

string s = "C++";
cout << s.length();

length() and size() are SAME

max_size()

Maximum possible size of string

string s;
cout << s.max_size();

System dependent

replace()

Replace part of string

string s = "Hello World";
s.replace(6,5, "C++");
cout << s;

Output

Hello C++

resize()

Change string size

string s = "HelloWorld";
s.resize(5);
cout << s;

Output

Hello

swap()

Swaps two strings

string a = "One";
string b = "Two";
a.swap(b);
cout << a << " " << b;

Output

Two One

Very fast → no deep copy.

!=

Inequality Operator

It checks whether two values are different

if(a != b)
		cout << "a and b are different";

Output

Example (Strings)

string s1 = "Hello";

		cout << "Strings are not equal";

Here != compares string contents, not memory addresses

[]

Subscript Operator

Used to access elements of:

  • arrays
  • strings
  • vectors

int arr[3] = {10, 20, 30};
cout << arr[1];;

Output

20

Index starts from 0

[] does NOT do bounds checking in string

s[10]; //unsafe

<<

Output

<< is used to send data to an output stream, usually the screen.

int x = 10;
cout << x;

Output

10

Multiple outputs

cout << "Value = " << x;

Data flows from program → output device

>>

Input

>> is used to take data form an input stream, usually the keyboard

int age;
cin >> age;

Data flows from input device → program
