15.1 Discriminate between string type and string and a C-type string.

  • Definition

C-type String

A C-type string is an array of characters terminated by a null character (\0).

It is inherited from the C language.

C++ String (string type)

A C++ string is an object of the string class that stores and manages text automatically.

It is part of the C++ Standard Library.

  • Declaration

TerminationEnds with '\0'No manual terminator
  • Memory Management
FeatureC-type StringC++ String

  • Operations & Ease to Use
OperationC-type StringC++ String
Assignmentstrcpy()= operator
Concatenationstrcat()+ operator

Lengthstrlen().length()
  • Safety
AspectC-type StringC++ String

Example Code

C-type String

#include <iostream>
#include <cstring>
using namespace std;

int main()
{
		char s1[20] = "Hello";
		char s2[20] = "World";
		strcat(s1, s2);
		cout << s1;
		return 0;
}

Output

HelloWorld

C++ String

#include <iostream>
#include <string>
using namespace std;

int main(){
		string s1 = "Hello";
		string s2 = "World";
		
		s1 = s1 + s2;
		cout << s1;
		return 0;
}

Output

HelloWorld

Conclusion

C-type strings are low-level, error-prone, and require manual handling, whereas C++ strings are safer, dynamic, and provide rich built-in functions. Therefore, C++ strings are preferred in modern C++ programming.

15.2 The following statements are available to read strings from the keyboard.

  1. cin >> s1;
  1. getline(cin,s1);

cin>>s1;

Meaning

  • Reads a string up to the first whitespace (space, tab, newline).
  • Input stops as soon as a space is encountered

Behavior

  • Skips leading whitespaces
  • Cannot read multi-word strings

Example

string s1;
cin >> s1;

Input

Hello World

Output stored in s1

Hello

getline(cin, s1);

Meaning

  • Reads the entire line of text, including spaces.
  • Input stops only when Enter key is pressed.

Behavior

  • Reads spaces
  • Suitable for full sentences

Example

string s1;
getline(cin, s1);

Input

Hello World

Output stored in s1

Hello World

Key Differences

Aspectcin >> s1getline(cin, s1)
Reads spaces❌ No✅ Yes
Stops atWhitespaceNewline (\n)
Input typeSingle wordFull line
Use caseNames, codesSentences, addresses
SafetySimpleMore flexible

Common Problem & Solution

Problem

Using getline() after cin>> may skip input.

int x;
string s;
cin >> x;
getline(cin, s); // gets skipped

Reason

  • cin >> x leaves a newline (\n) in the buffer

Solution

cin.ignore();
getline(cin,s);

Conclusion

cin >> s1 is used to read a single word without spaces, whereas getline(cin, s1) is used to read an entire line including spaces. Therefore, getline() is preferred when input contains spaces.

15.4 We can access string elements using

  1. at() function
  1. subscript operator[ ]

Compare their behavior.

  1. at() Function

Description

The at() function is a safe method to access characters of a string.

Behavior

  • Performs bounds checking
  • Throws an exception if index is invalid
  • Safer for runtime access

Syntax

s.at(index);

Example

string s = "Hello";
cout << s.at(1);

Output

e

Out-of-range access

s.at(10); // throws exception
  1. Subscript Operator []

Description

The subscript operator provides direct access to string elements.

Behavior

  • No bounds checking
  • Faster but unsafe
  • Out-of-range access leads to undefined behavior

Syntax

s[index];

Example

string s = "Hello";
cout << s[1];

Output

e

Out-of-range access

s[10]; // undefined behavior

Comparison Table

Featureat() Function[] Operator
Bounds checking✅ Yes❌ No
SafetyHighLow
SpeedSlowerFaster
ExceptionThrows exceptionNo exception
Recommended useSafe accessPerformance-critical

Conclusion

The at() function provides safe access with bounds checking and exception handling, whereas the subscript operator [] provides faster access without bounds checking. Therefore, at() is preferred for safety and [] for performance.

15.7 Defend the correctness of the following statements:

a. For using string class, we must include the header <string>.

The statement is correct because the string class is defined in the <string> header file of the C++ Standard Library.

Without including this header, the compiler does not recognize the string class and will generate an error.

b. string objects are null terminated.

The statement is correct because a C++ string object stores its characters internally in a null-terminated character array to maintain compatibility with C-style strings.

Although the programmer does not manually handle the null character (\0), the string class ensures that:

  • The internal buffer ends with \0
  • Functions like c_str() and data() can safely return a C-style string

Important Clarification

  • The null character is managed automatically
  • \0 is not counted in string::length()
  • Users do not need to add or remove the null terminator

c. The elements of a string object are numbered from 0.

The statement is correct because C++ strings follow zero-based indexing, just like arrays and other STL containers.

This means the first character of string is stored at index 0, the second at index 1, and so on.

Zero-based indexing is a standard design choice in C and C++, allowing:

  • Efficient memory addressing
  • Consistency with arrays, vectors, and iterators
  • Easy integration with pointer arithmetic

d. Objects of string class can be copied using the assignment operator

The statement is correct because the C++ string class overloads the assignment operator (=) to support deep copying of string objects.

When one string object is assigned to another, the contents of the source string are copied into the destination string.

Each string object maintains its own memory, so modifying one string does not affect the other.

c. Function end() returns an iterator to the invoking string object

The statement is correct because the end() function of a C++ string object returns an iterator that refers to the position just past the last character of the invoking string object.

This Iterator:

  • Does not point to a valid character
  • Acts as a sentinel marking the end of the string
  • Is mainly used in loops and algorithms to control traversal

📌 shrink_to_fit()

What does shrink_to_fit() do?

  • It requests the string to reduce its capacity to match its current size
  • Frees unused (extra) memory
  • It is a non-binding request (compiler may or may not reduce capacity)
